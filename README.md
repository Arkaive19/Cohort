# Hollow Knight Save Editor

A CLI tool to launch Multiple Sober Instances This Project was Inspired by [@Bloodorca's](https://github.com/dim-ghub) [Withdrawal](https://github.com/dim-ghub/Withdrawal) project.

## Installation

```bash
npm install -g @arkaive19/cohort
```

## Usage

```bash
  cohort <option> [arguments]

Options:
  add <name>             Create an instance
  list                   List instances
  rename <old> <new>     Rename an instance
  delete <name>          Delete an instance
  run <name>             Launch Sober
  import <name>          Import default Sober settings
  --help                 Show this help | (--h)
  --version              Show version   | (--v)
```

- `<name>`: Name of Instance
- `<old|new>`: The old instance name and new instance name.

## Example

```bash
cohort add new_instance
cohort run new_instance
```

### Notes

- OS must be Linux based distro.
- flatpak and sober must be installed
